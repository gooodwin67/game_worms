# Worms · Hot Seat

Исходная реализация пошаговой артиллерийской игры: Three.js + Rapier2D compat (WASM), ортографическая сцена XY. Сохранена интеграция шаблона с Яндекс Играми.

## Модули

- `src/game/core.js`: аккумулятор с шагом 1/60 с, ограничение догоняющих шагов, автомат WAITING_INPUT → CHARGING_SHOT → ACTION_RESOLVING → SETTLING → NEXT_TURN. SETTLING требует 0,6 с покоя всех живых червей и наличия опоры; принудительного переключения по таймауту нет.
- `src/game/terrain.js`: карта 96×54 единицы, маска Canvas 768×432, ShaderMaterial с discard. Чанки 16×16 пикселей; твердые пиксели объединяются в прямоугольные статические коллайдеры. createExplosion(x,y,radius) синхронно вырезает круг и перестраивает только пересекающиеся чанки. Разрешение столкновений — 0,125 игровой единицы.
- `src/game/weapons.js`: экспорт арсенала и отдельного планировщика ботов.
- `src/game/bot.js`: профили трёх сложностей, выбор целей и оружия, проверка полной дуги полёта, радиуса взрыва и безопасности союзников, а также исполнение многоэтапных действий.
- `src/game/particles.js`: один THREE.Points, кольцевой пул 4096 частиц, баллистика и затухание на GPU.
- `src/game/game.js`: настройка 2–6 команд, 1–4 червя с 100 HP в каждой, управление человеком/ботом, камера, HUD, перезапуск и обработка гибели.

## Управление

A/D или ←/→ — движение; W — прыжок с земли. Мышь или ↑/↓ — направление. Удерживать пробел или левую кнопку мыши — заряжать, отпустить — стрелять. Кнопки HUD — оружие. 1–5 — запал гранаты до броска. Колесо — масштаб камеры. Новый матч — возврат к настройкам.

## Установка

После изменения зависимостей выполните `npm install`. Команды проекта: `npm run dev`, `npm run build`, `npm run preview`.

## Аудио

Игровые SFX лежат в `public/audio`, а единая точка управления — `src/core/audio.js`. Для добавления нового звука достаточно положить WAV-файл в `public/audio` и зарегистрировать его в конструкторе `AudioManager` через `registerSfx(name, fileName, options)`. Одноразовые эффекты запускаются методом `play(name)`, зацикленные — `startLoop(name)` и `stopLoop(name)`.

Для заряда оставлен один беспитчевый вариант `energy_charge_natural.wav` с вибрацией, воздухом, электрическими потрескиваниями и металлическим резонансом. Он выбран основным, запускается при удержании пробела или ЛКМ и доступен для прослушивания единственной кнопкой «Натуральный» в HUD. После успешного выстрела запускается `energy_shot.wav`.

Добавлены и подключены SFX `explosion.wav`, `footstep.wav`, `jump.wav` и `landing.wav`: взрыв срабатывает при детонации, шаги — с ограничением частоты во время движения, прыжок — при старте прыжка, падение — при заметном приземлении.

## Границы реализации

Цель — 60 FPS; производительность не измерялась. Рендер переиспользует меши, векторы и буферы; абсолютный zero-GC не гарантируется: Rapier возвращает JS-объекты, HUD обновляет строки 20 раз в секунду, взрывы создают новые локальные коллайдеры. Частицы отскакивают от условной плоскости около точки взрыва, а не от разрушаемой маски. Баллистический прогноз ИИ использует текущую маску рельефа, но не предсказывает последующее движение цели или сложные рикошеты гранат. Интерфейс матча на русском, полноценного сенсорного управления движением нет. Количество команд ограничено шестью в текущем интерфейсе.

Сборки, тесты, сервер, браузер и визуальные проверки при внесении этих изменений не запускались согласно указаниям пользователя.

## Расширенный арсенал и случайные карты

Каждый новый матч использует новый случайный seed, несколько волн рельефа и извилистые тоннели с камерами. Стартовые позиции учитывают ширину червя и высоту поверхности; тоннели проходят ниже стартового слоя.

- Прыжок W направлен вверх и вперёд по взгляду; направление видно по глазу. A/D меняют направление и плавно разгоняют червя. После приземления трение кратковременно уменьшается, сохраняя скольжение.
- Самонаводящаяся ракета: ЛКМ отмечает точку; затем прицелиться и зарядить пробелом. Ракета плавно поворачивает к отмеченной точке после короткого прямого полёта.
- Осколочная граната: после запала распадается на семь физических взрывающихся осколков.
- Апперкот: удар перед червём с подбрасыванием цели.
- Динамит: взрыв через 4 секунды; первые 2 секунды можно отойти.
- Мина: остаётся между ходами, активируется через 1,5 секунды, срабатывает при приближении. Владелец становится целью после выхода из зоны установки. Взрывы вызывают цепную реакцию.
- Овечка: бежит вперёд, пытается перепрыгивать препятствия; повторный пробел/ЛКМ, противник рядом или истечение 9 секунд вызывают взрыв.
- Air strike: ЛКМ выбирает участок для шести падающих бомб.
- Бурение: вырезает проход вниз на протяжении 2,2 секунды.
- Телепорт: ЛКМ в свободном месте; занятая позиция отклоняется без расхода хода.
- При тяжёлом падении боец переворачивается головой вниз, после приземления поднимается и отряхивается; короткие сходы со склонов не считаются падением.
- Суммарное здоровье команд отображается отдельными цветными панелями снизу по центру.
- Боты ждут две секунды перед действием. Сложный ИИ оценивает цели и позиции, использует базуку, гранаты, самонаводящуюся ракету, пистолет, узи, авиаудар, овцу, пинок, динамит, мину и телепорт. Для очередей, овцы и отхода после установки взрывчатки предусмотрены отдельные этапы управления.
- Частицы разрушенного грунта получают цвета из удаляемого участка карты; для процедурного рельефа используется соответствующая палитра почвы и травы.

Снаряды используют общий пул из 80 визуальных объектов. Завершение действия ждёт всех активных снарядов и осколков; неактивированные мины не удерживают ход. ИИ пока использует базуку. Новые предметы имеют условную геометрическую графику.
